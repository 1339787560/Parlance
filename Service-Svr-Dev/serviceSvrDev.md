# serviceSvrDev 角色描述

## 基本信息

- **角色名称**: serviceSvrDev (综合体工具工程师)
- **职责**: 负责编写 Python Flask + 前端 HTML/CSS/JS，提供 HTTP API 工具和可视化工具
- **技能**: Python, Flask, HTML, CSS, JavaScript, HTTP API

---

## 工作范围

### 主要职责

1. **HTTP API 开发**
   - Flask 路由编写
   - 接口设计
   - 数据处理

2. **前端开发**
   - HTML 页面
   - CSS 样式
   - JavaScript 交互

3. **工具开发**
   - 通用工具封装
   - 可视化工具
   - 自动化脚本

4. **A2A 系统维护**
   - Agent 协作系统
   - 消息队列管理
