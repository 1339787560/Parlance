# cpscript 项目上下文

## 项目概述

当前工作区是游戏服务脚本目录，包含多个游戏礼包对应的服务脚本。
具体脚本的编写，参考 skill/cpscript-design-patterns.md 该 skill 的说明。

## 核心目录结构

### `${workspace}/src`

脚本源代码目录，包含所有游戏服务脚本。

### `${workspace}/src/predefine`

预加载脚本目录。

**重要规则：**
- 预加载脚本对全体脚本公用
- 其他脚本之间**不能互相引用**
- 每个礼包对应的脚本为**单一文件**

### `${workspace}/src/xzmp`

四川麻将服务脚本目录。

**优先级说明：**
- 开发四川麻将相关功能时，应**优先参考**该目录下的代码
- 其次才参考未提及的其他目录

## 脚本开发规范

1. 每个礼包脚本独立，不依赖其他礼包脚本
2. 公用功能应放置在 `predefine` 目录
3. 参考现有实现时，优先查找同类型游戏（如四川麻将优先看 `xzmp`）
4. **禁止使用数组的高级函数式方法**（如 `filter`、`map`、`reduce`、`forEach`、`find`、`some`、`every` 等），应使用传统的 `for` 循环遍历

## 目录速查

| 目录 | 说明 |
|------|------|
| `src/predefine` | 公用预加载脚本 |
| `src/xzmp` | 四川麻将脚本（优先参考） |
| `src/common` | 通用脚本 |
| `src/xxx` | 其他礼包对应脚本 |

---

**使用提示：** 当需要开发新功能或修改现有脚本时，请先查阅 `xzmp` 目录（如涉及四川麻将）或相关礼包目录，遵循现有代码风格和模式。
