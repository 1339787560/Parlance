# CP原型文档 - 每日问答模块

## 一、模块概述

| 项目 | 说明 |
|------|------|
| 模块名称 | 每日问答 |
| 功能说明 | 玩家每日答题获取奖励的活动模块，错题优先复习 |
| 入口位置 | 大厅界面入口节点 |
| 刷新时间 | 每日0点 |

---

## 二、界面结构

### 2.1 主界面布局

```
┌─────────────────────────────────────────────────┐
│  [返回]              每日问答            [规则] │
├─────────────────────────────────────────────────┤
│                                                 │
│   ┌─────────────────────────────────────────┐  │
│   │          题目内容区域                    │  │
│   │     （文本/牌型展示区域）                │  │
│   └─────────────────────────────────────────┘  │
│                                                 │
│   ┌─────────┐  ┌─────────┐                     │
│   │ 选项A   │  │ 选项B   │                     │
│   └─────────┘  └─────────┘                     │
│                                                 │
│   ┌─────────────────────────────────────────┐  │
│   │            答题解析区域                  │  │
│   │          （答对/答错后展示）             │  │
│   └─────────────────────────────────────────┘  │
│                                                 │
├─────────────────────────────────────────────────┤
│  进度: 3/10        累计奖励: 9000金币           │
│                                                 │
```

### 2.2 界面元素说明

| 元素 | 类型 | 说明 |
|------|------|------|
| 题目内容区 | Text | 显示题目文本内容 |
| 牌型展示区 | CardDisplay | 展示麻将牌型（有huinfos时显示） |

| 领取奖励按钮 | Button | 答完所有题目后显示，点击领取 |

## 四、消息协议

### 4.1 请求题目信息 (REQINFO)

**请求消息**

| 字段 | 类型 | 说明 |
|------|------|------|
| - | - | 无参数 |

**返回消息**

| 字段 | 类型 | 说明 |
|------|------|------|
| status | int | 状态码 |
| questions | array | 今日题目列表 |
| answerednum | int | 已答题数量 |
| totalcount | int | 总题目数量 |

**单题信息结构**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 题目ID |
| content | string | 题目内容 |
| options | array | 选项列表（按随机顺序） |
| prize | int | 答对奖励金额 |
| answer | int | 答题状态：0未答/1正确/>1错误 |
| huinfos | array | 牌型展示信息（可选） |

### 4.2 提交答案 (REQANSWER)

**请求消息**

| 字段 | 类型 | 说明 |
|------|------|------|
| questionid | int | 题目ID |
| answer | int | 选项序号（1或2） |

**返回消息**

| 字段 | 类型 | 说明 |
|------|------|------|
| status | int | 状态码 |
| correct | int | 是否正确：1正确/0错误 |
| correctoption | int | 正确答案序号（错误时返回） |
| explain | string | 答题解析 |
| prize | int | 本题奖励金额（正确时返回） |
| totalprize | int | 当前累计奖励 |

### 4.3 领取奖励 (REQPRIZE)

**请求消息**

| 字段 | 类型 | 说明 |
|------|------|------|
| - | - | 无参数 |

**返回消息**

| 字段 | 类型 | 说明 |
|------|------|------|
| status | int | 状态码 |
| prize | int | 最终奖励金额 |
| allcorrect | int | 是否全对：1全对/0非全对 |

## 五、牌型展示规格

### 5.1 牌区类型

| type值 | 说明 |
|--------|------|
| 1 | 暗杠 |
| 2 | 明杠 |
| 3 | 碰 |
| 4 | 手牌 |

### 5.2 牌索引映射

| 范围 | 牌面 |
|------|------|
| [1,9] | 1万-9万 |
| [11,19] | 1条-9条 |
| [21,29] | 1筒-9筒 |
| [35] | 红中 |

### 5.3 展示格式

```json
"huinfos": [
    {
        "type": 4,
        "cardidxs": [1, 2, 3, 4, 5, 6]
    }
]
```

客户端根据type值确定牌区展示样式，根据cardidxs渲染具体牌面。

## 六、奖励规则

### 6.1 基础奖励

每答对一题获得该题配置的prize金额（当前配置为3000金币/题）。

### 6.2 全对奖励

答对所有题目时，额外获得 allcorrect - 1倍数的奖励（当前配置为5倍）。

### 6.3 奖励计算示例

| 答对数 | 基础奖励 | 全对加成 | 最终奖励 |
|--------|----------|----------|----------|
| 10题全对 | 30,000 | +5 | 35,000 |
| 8题对 | 24,000 | +0 | 24,000 |
| 5题对 | 15,000 | +0 | 15,000 |

## 七、错误码说明

| status | 说明 | 客户端处理 |
|--------|------|------------|
| 0 | 成功 | 正常流程 |
| 1 | 配置不存在 | 显示错误提示 |
| 2 | 玩家数据获取失败 | 显示错误提示 |
| 3 | REQANSWER已答完/REQPRIZE未答完 | 显示状态提示 |
| 4 | 题目ID不匹配 | 刷新题目列表 |
| 5 | 题目已回答 | 刷新题目列表 |
| 6 | 持久化存储失败 | 显示错误提示 |

## 八、配置文件

配置文件路径：`src/xzmp/cmdailyquestion_xzmp.jsonc`

### 8.1 配置结构

```json
{
    "isenable": 1,
    "guid": "xxx",
    "typenum": [2, 2, 2, 2, 2],
    "prize": 3000,
    "allcorrect": 5,
    "questionnumlimit": 9,
    "subject": [
        {
            "id": 1,
            "type": 1,
            "content": "题目内容",
            "explain": "解析说明",
            "options": ["正确答案", "错误答案"],
            "huinfos": []
        }
    ]
}
```

### 8.2 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| isenable | int | 模块开关：1启用/0禁用 |
| guid | string | 发奖兑换ID |
| typenum | array | 各类型题目数量 |
| prize | int | 每题答对奖励金额（全局配置） |
| allcorrect | int | 全对额外奖励倍数 |
| questionnumlimit | int | 每日题目上限（预留） |
| subject | array | 题目列表 |
| subject[].id | int | 题目唯一标识 |
| subject[].type | int | 题目类型（1-5） |
| subject[].content | string | 题目内容 |
| subject[].explain | string | 答题解析 |
| subject[].options | array | 选项列表，答案放首位 |
| subject[].huinfos | array | 牌型展示信息（可选） |

## 九、注意事项

1. **错题优先复习**：昨日答错的题目会优先出现在今日题库
2. **选项随机顺序**：每题选项显示顺序由服务器随机打乱
3. **每日刷新**：题库每日0点刷新
4. **一次答题**：每日只能答一次，答完领取奖励后当日不可再答
5. **牌型展示**：type=4的题目需要展示麻将牌型，客户端需支持牌面渲染
